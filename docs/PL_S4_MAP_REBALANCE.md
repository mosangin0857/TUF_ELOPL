# TFPL S4 정규 경기 개인전 맵 재배치 (2026-10-24)

운영진(PL 담당) 요청: 팀별 · 티어별로 개인전 맵이 고르게 오도록 **11/03(1R-10M)부터 36경기의 개인전 맵만** 바꿈. DB 데이터만(코드 변경 없음).

- 그대로: 11/03 전 9경기(1R-1M~9M, 팀장들이 엔트리 인원 모집 중) 전체, 날짜 · 대진 · 홈/원정 · 요일 균형, 세트 번호별 티어(10-22 세트 순서 재배치 그대로), 팀플 세트
- 지킨 것: 티어(1~4티어 · 홈지정 · 에결)별 전체 맵 6~7회, 한 경기 안 개인전 맵 중복 없음, **한 팀 기준** 이어지는 두 경기에서 같은 티어 · 같은 맵 없음 (다른 팀끼리 다음 날 같은 맵은 상관없음)
- 결과: 팀별 · 티어별 맵 횟수 0~5회 → 1~3회(대부분 2~3회, 1회 6칸 — 고정된 앞 경기 때문), 팀별 맵 합계 10~15회 → 12~14회
- 홈지정은 홈 팀이 고르기 전 정해 둔 개인전 맵(`solo_map`) 기준. 바꾼 자리 178곳(36경기 모두)
