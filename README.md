# TUF_ELOPL

스타크래프트 1 **TuF 클랜** 통합 사이트 — 클랜하우스(대문) · ELO 보드 · 프로리그 · 개인리그.

## 시작하기

```bash
npm install
cp .env.example .env.local   # Supabase URL · anon 키 입력
npm run dev                  # http://localhost:3000
```

## 현재 상태

| 화면 | 상태 |
| --- | --- |
| 전체 레이아웃 (사이드바 · 상단 바 · 영역 탭 · 라이트/다크) | 완료 |
| 클랜하우스(대문) | 화면 완료 · 예시 데이터 |
| ELO 보드 › 대시보드 | **실제 DB 연결** (시즌 요약 · 선수/맞대결 전적 검색 · 최근 전적) |
| ELO 보드 나머지 탭 · 프로리그 · 개인리그 · 관리자 설정 · 공지 · 일정 · 클랜원 | 준비 중 |

작업 규칙(영역 담당, DB 테이블 이름, 디자인 토큰)은 [CLAUDE.md](CLAUDE.md)에 있습니다.
