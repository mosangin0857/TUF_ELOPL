# TUF_ELOPL

스타크래프트 1 **TuF 클랜** 통합 사이트 — 클랜하우스(대문) · ELO 보드 · 프로리그 · 개인리그.
배포: https://tufelopl.vercel.app

## 시작하기

```bash
npm install
cp .env.example .env.local   # Supabase 값 입력 (설명은 .env.example)
npm run dev                  # http://localhost:3000 — 저장하면 바로 반영
```

## 현재 상태

| 화면 | 상태 |
| --- | --- |
| 전체 레이아웃 (사이드바 · 상단 바 · 영역 탭 · 라이트/다크) | 완료 |
| 클랜하우스(대문) | 화면 완료 · 선수 검색만 실제 DB, 나머지 섹션은 데이터 연결 전 |
| ELO 보드 › 대시보드 | **실제 DB** (시즌 요약 · 선수/맞대결 전적 검색 · 최근 전적) |
| 클랜원 | **실제 DB** (명단 · 필터 · 관리자 메모 · 수정 · 탈퇴 · 복귀 · 완전 삭제) — 로그인 전에는 잠금 |
| 관리자 로그인 | 미구현 |
| ELO 나머지 탭 · 프로리그 · 개인리그 · 관리자 설정 · 공지 · 일정 | 준비 중 |

작업 규칙(영역 담당, DB 규칙, 권한, 환경변수, 디자인 토큰, 다음 할 일)은 **[CLAUDE.md](CLAUDE.md)** 에 있습니다.
