## 이 SQL들과 함께 정한 규칙 (2026-09-28)

**방송 BJ (007)**
- 경기 결과 입력 때 그날 방송한 BJ 닉네임을 기록한다. 관리자 설정 › BJ 관리의 클랜 BJ 목록에서 고르거나 직접 입력, 여러 명 가능.
- clan_bjs와 FK로 묶지 않고 이름으로 저장 (BJ를 지우거나 이름을 바꿔도 지난 기록 유지).
- PL 관리 사이드바 'BJ 방송 횟수'로 시즌 집계.

**세트 티어 (008)**
- 세트마다 정해진 티어가 있고 그 티어 선수만 출전 가능. 경기 등록 · 수정의 세트 구성과 엑셀 일괄 등록 둘 다에서 정한다.
- 팀플(2:2 · 3:3 · 4:4) · 홈/어웨이 지정 · ACE 결정전은 티어 제한 없음.
- 엔트리 제출: 그 티어 선수만 고를 수 있고 서버에서도 검사. 결과 입력(관리자): 막지 않고 티어가 다르면 경고만 (시즌 중 티어 변경 대비).
- 일정 화면에 '1티어 · 제인도'처럼 표시.

## 지정 세트 규칙 변경 (2026 시즌 공지, 2026-10-05)

**지정 티어 개인전 또는 생컨 (009)**
- 홈 지정(정규 · 플레이오프) · 어웨이 지정(플레이오프)에서 지정 팀이 둘 중 하나를 고른다. 이전의 '팀플 2:2~4:4 + 맵풀 맵' 선택은 없어짐.
- 지정 티어 개인전: 1~4티어 중 선택 → 그 티어 선수만 출전 (`tier`), 맵은 관리자가 경기 등록 때 적은 개인전 맵(`solo_map`).
- 생컨: 2:2 · 맵 폴리포이드 고정, 티어합도 지정 팀이 정함 (`tier_sum`). 출전 두 선수 티어 합이 **그 값 이상**이어야 함 (1티어가 최상위라 합이 작을수록 센 조합). 엔트리 제출 때 서버에서 검사, 결과 입력(관리자)은 경고만.
- 일반 세트의 팀플2~4(2:2~4:4)는 그대로. 팀플 맵 변경(로스트템플 · 네오 기요틴 · 헌터 · 패러다임)은 맵풀로 관리.
